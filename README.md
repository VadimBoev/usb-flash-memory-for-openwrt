# USB Flash Memory for OpenWrt

Настройка USB-флешки в качестве дополнительного хранилища для **TP-Link Archer C6U v1** под управлением **OpenWrt 24.10.8**.

В этой инструкции:
- Подключение USB-накопителя.
- Установка необходимых драйверов.
- Форматирование флешки в ext4.
- Перенос `/overlay` на USB.
- Создание Swap-файла для дополнительной виртуальной памяти.

> [!CAUTION]
> **Все данные на USB-флешке будут полностью удалены!**
>
> Перед началом сохраните важные файлы.
>
> Команды форматирования и настройки накопителя выполняйте внимательно: ошибка в выборе устройства может привести к потере данных.

## Требования

- TP-Link Archer C6U v1.
- OpenWrt 24.10.8.
- USB-флешка.
- Ноутбук или компьютер с SSH-клиентом.
- Доступ к роутеру с правами `root`.

## Этап 1. Установка драйверов USB и определение флешки

Вставьте USB-флешку в USB-разъём роутера.

Откройте терминал на компьютере и подключитесь к роутеру:

```sh
ssh root@192.168.1.1
```

Введите пароль администратора роутера. При вводе символы пароля не отображаются.

Установите драйверы USB-накопителей, файловую систему ext4 и необходимые утилиты:

```sh
opkg update
opkg install kmod-usb-storage kmod-usb-storage-uas usbutils block-mount kmod-fs-ext4 e2fsprogs parted
```

Перезагрузите роутер:

```sh
reboot
```

Подождите 1–2 минуты и снова подключитесь по SSH:

```sh
ssh root@192.168.1.1
```

Проверьте обнаружение USB-накопителя:

```sh
ls -l /dev/sd*
```

Возможные варианты:

- `/dev/sda1` — обнаружен раздел флешки.
- `/dev/sda` — обнаружен сам накопитель, но раздел не отображается.

**Важно:** дальнейшие команды форматирования необходимо выполнять только после проверки правильного устройства и его разделов. Если отображается только `/dev/sda`, не форматируйте его вслепую.

## Этап 2. Форматирование и перенос `/overlay` на флешку

В примерах используется `/dev/sda1`.

Если у вас другое устройство, сначала убедитесь в его правильности.

### 2.1. Форматирование в ext4

> [!WARNING]
> Следующая операция уничтожит все данные на выбранном разделе!

```sh
mkfs.ext4 /dev/sda1
```

Если появится запрос подтверждения, проверьте, что выбрано правильное устройство, и подтвердите форматирование.

### 2.2. Копирование системных файлов

Подключите флешку:

```sh
mount /dev/sda1 /mnt
```

Скопируйте содержимое текущего `/overlay`:

```sh
tar -C /overlay -cvf - . | tar -C /mnt -xf -
```

Отключите флешку:

```sh
umount /mnt
```

### 2.3. Настройка автоматического подключения

Обнаружьте конфигурацию накопителя:

```sh
block detect | uci import fstab
```

Настройте точку монтирования:

```sh
uci set fstab.@mount.target='/overlay'
uci set fstab.@mount.enabled='1'
uci commit fstab
```

Перезагрузите роутер:

```sh
reboot
```

Подождите 1–2 минуты и подключитесь по SSH.

Проверьте использование памяти:

```sh
df -h
```

**Ожидаемый результат:** в строке `/overlay` должен отображаться размер USB-накопителя.

> [!NOTE]
> Перед продолжением убедитесь, что `/overlay` действительно находится на USB-флешке. Если флешка не подключилась при загрузке, не продолжайте настройку Swap.

## Этап 3. Создание Swap-файла

Swap — это виртуальная память, которая позволяет Linux временно использовать накопитель как дополнительное пространство для хранения страниц памяти.

Для роутера со 128 МБ RAM Swap может служить дополнительным резервом при нехватке оперативной памяти.

> [!WARNING]
> USB-флешка значительно медленнее RAM. Постоянное использование Swap может снизить производительность и ускорить износ накопителя.
>
> Swap не гарантирует отсутствие зависаний и перезагрузок.

### 3.1. Проверка свободного пространства

```sh
df -h /overlay
```

Убедитесь, что свободного места достаточно для файла Swap.

### 3.2. Создание файла Swap

В качестве примера используется размер 512 МБ.

```sh
dd if=/dev/zero of=/overlay/swap.page bs=1M count=512
```
> [!WARNING]
> Команда dd может занять от 20 секунд до 3 минут

Установите права доступа:

```sh
chmod 0600 /overlay/swap.page
```

Создайте область подкачки:

```sh
mkswap /overlay/swap.page
```

### 3.3. Настройка автоматического подключения Swap

Добавьте Swap в конфигурацию fstab:

```sh
uci add fstab swap
uci set fstab.@swap[-1].device='/overlay/swap.page'
uci set fstab.@swap[-1].enabled='1'
uci commit fstab
```

Активируйте Swap:

```sh
swapon /overlay/swap.page
```

Проверьте результат:

```sh
free -h
```

## Этап 4. Настройка Swappiness (сомнительно, не устанавливал себе лично, можно пропустить)

Параметр `vm.swappiness` определяет склонность ядра Linux к использованию Swap.

Значение `10` означает, что система будет менее охотно использовать Swap, чем при стандартном значении `60`.

Добавьте параметр в конфигурацию:

```sh
echo "vm.swappiness=10" >> /etc/sysctl.conf
```

Примените настройки:

```sh
sysctl -p
```

Проверьте текущее значение:

```sh
cat /proc/sys/vm/swappiness
```

Ожидаемый результат:

```text
10
```

## Этап 5. Проверка результата

Выполните:

```sh
free -h
```

Пример ожидаемого вывода:

```text
               total        used        free
Mem:           120Mi        ...         ...
Swap:          512Mi        ...         ...
```

Проверьте подключение USB:

```sh
df -h
```

Убедитесь, что `/overlay` использует USB-накопитель.

Проверьте активность Swap:

```sh
swapon --show
```

## Итог

После выполнения инструкции:

- USB-флешка используется для хранения `/overlay`.
- Файлы OpenWrt располагаются на USB-накопителе.
- Создан дополнительный Swap объёмом 512 МБ.
- Swap настроен на автоматическое подключение.
- Параметр `vm.swappiness` установлен на 10.

> [!IMPORTANT]
> USB-флешка становится важной частью работы роутера. Не извлекайте её во время работы устройства.
>
> Рекомендуется периодически проверять состояние накопителя и сохранять резервную копию конфигурации OpenWrt.
